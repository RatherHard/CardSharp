# MVP 阶段设计：卡锐思 CardSharp：可拓展的 AI 卡片助手

## 产品定位

产品定位是**可拓展的 AI 卡片助手**。MVP 的目标用户是面对大量记忆性学习任务的各领域学习者

## MVP 用户需求

1. 用户把自己的资料在 Agent 帮助下转成记忆卡片集
2. 用户在手机上根据 Agent 安排的长期学习计划进行持续性记忆学习
3. 用户能够和 Agent 助手互动并咨询提问关于拥有的卡片集的相关问题以及外部问题
4. 用户需要一个通用的卡片系统

## 通用卡片系统

MVP 需要包含一个通用卡片系统，通用卡片系统是不同类型卡片集合的共同基石

### 制卡

需要一个统一的制卡调用接口，输入用户的指令、交互行为以及资料，经过不同类型的 Agent 处理，得到期望的卡片集合

制卡资料保存与关联是通用的模块，将制卡资料与对应卡片集合关联

制卡结果预览与确认是通用模块

### 卡片管理

卡片集合管理系统：设计简单的单层文件夹以便于用户管理分类，同时有筛选选项、用户自定义标签、搜索功能

卡片编辑与搜索：针对卡片的全局搜索/指定卡片集合搜索；统一的卡片编辑；

### 卡片集合运行

有一个统一的运行 Agent，会分类统筹各个卡片集合（不限类型）的运行，向用户发送通知、推荐，规划一些安排，其行为有一个接口，可以接入不同卡片类型对应的 agent，这一过程也需要在交互中进行

## 独立 Agent 助手

MVP 需要包含一个独立的 Agent 助手，统筹整个应用的相关任务，如解决疑惑、根据用户需求主动制卡和安排/调整运行，同时将用户的所有资料/卡片组织成一个或者多个知识库（创新点）
