## 2. 本地怎么跑

```bash
cd mobile

flutter pub get
dart run build_runner build --delete-conflicting-outputs   # 改了 freezed/JSON 模型后才需要
flutter run -d <device>
```

提交前的三道门禁（与 CI 一致）：

```bash
dart format --line-length 100 --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test --coverage
```

> `--fatal-infos` 是硬要求：任何 info 级 lint 都会让 CI 失败。
> `build_runner` 产物（`*.freezed.dart`、`*.g.dart`）**必须提交**，CI 会用 `git status --porcelain lib` 校验。

## 3. 代码约定（不要走样）

分层固定为四层，禁止跨层调用：

```
Widget → Notifier（Riverpod） → UseCase → Repository（Fake/Http 实现）
```

| 层 | 位置 | 规则 |
| --- | --- | --- |
| Presentation | `features/<f>/presentation/` | 只依赖 application 与 domain；**禁止直接 import data 层** |
| Application | `features/<f>/application/` | `Notifier` / `AsyncNotifier` + UseCase 的 `Provider` |
| Domain | `features/<f>/domain/` | 实体（freezed）、抽象接口、常量；无 Flutter 依赖 |
| Data | `features/<f>/data/` | 接口的 Fake / Http 实现 |

接后端时**只改两处**：新增 `HttpXxxRepository`，把 `xxxRepositoryProvider` 的实现换掉。页面、状态、路由都不用动。

其他约定：

- 主题：`mobile/lib/core/theme/app_theme.dart`（seed `0xFF4F46E5`，Material 3，跟随系统深浅色），不要在页面里硬编码颜色
- 文案：统一走 `mobile/lib/core/l10n/app_strings.dart`，不要在 Widget 里写中文字面量
- 路由：`mobile/lib/core/router/app_router.dart` 的 `routerProvider`，登录守卫在 `redirect` 里
- 3.50 起 Material 已拆包：统一 `import 'package:material_ui/material_ui.dart';`，**不要**再用 `package:flutter/material.dart`

## 5. 构建环境坑（Windows 本机实测）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `services.gradle.org` 连接失败 | 网络不可达 | Gradle 发行包已预置在 `~/.gradle/wrapper/dists/`；换机器需自行准备或用镜像 |
| `Error resolving plugin dev.flutter.flutter-plugin-loader` | 自定义 `~/.gradle/init.gradle` 在 `allprojects` 里 `clear()` 仓储，与仓库 `settings.gradle.kts` 的 PREFER_SETTINGS 冲突 | init 脚本只增强 `pluginManagement` / `dependencyResolutionManagement` 仓储，不要清空 project 仓储 |
| `AGP version 9.1.0 is lower than Flutter's minimum` | Flutter 3.50 要求 AGP ≥ 9.1.1 | 已升到 **9.3.1**（`mobile/android/settings.gradle.kts`） |
| Gradle 9.3.1 即将停止支持 | 3.50 的警告 | 已升到 **Gradle 9.5.0**（`mobile/android/gradle/wrapper/gradle-wrapper.properties`） |
| `androidx.core:1.19.0` / `flutter_local_notifications` 要求更高 compileSdk | — | 已改为 `compileSdk = 37` + 开启脱糖 + `desugar_jdk_libs:2.1.5`（`mobile/android/app/build.gradle.kts`） |
| GitHub HTTPS 连接被重置 | 网络 | 走 SSH：`git@github.com` 已指向 `ssh.github.com:443` |

以上三处 Android 配置改动都带行内注释，原因同步记录在 [AGENTS.md](../AGENTS.md) §10「已知环境限制」。
